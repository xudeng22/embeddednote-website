# 关于 EmbeddedNote

欢迎来到 **EmbeddedNote · 嵌入式杂谈**。

EmbeddedNote 是一份面向工程师、硬件开发者与技术爱好者的中英双语技术媒体，关注嵌入式系统、半导体器件、电子设计和开源项目。我们希望把有价值的项目资料、硬件细节与工程经验整理成便于检索、阅读和参考的内容。

## 我们关注什么

网站目前设有六个技术频道：

- **开源项目**：从 GitHub 仓库、项目结构、源代码与硬件资料中理解设计思路。
- **MCU 与 SoC**：微控制器、处理器、开发平台以及相关软硬件生态。
- **硬件设计**：原理图、PCB、电源、接口电路和器件选型。
- **通信技术**：BLE、Wi-Fi、NFC、CAN 等协议与工程应用。
- **显示技术**：电子纸、TFT、Mini LED 与显示驱动相关技术。
- **开发工具**：调试设备、仿真工具、开发环境及测试方法。

除了介绍项目做了什么，我们也尽可能回答它**如何实现、使用了哪些关键器件、有哪些设计取舍，以及还存在哪些限制**。

## 编辑原则

我们重视准确性、可读性和工程价值。文章会尽可能参考原始项目仓库、官方文档、数据手册和公开技术资料；对于尚未独立验证的性能数据或产品声明，会区分原作者提供的信息与我们的分析，不把未经验证的描述写成实测结论。

中英文内容以技术含义准确为先，必要时根据不同读者的表达习惯调整语言，但不改变技术参数、原理和原始资料的含义。

## 编辑方法与证据等级

我们把工程信息区分为三种类型：

1. **一手资料整理：** 来自厂商数据手册、官方文档、开源仓库、公开原理图或项目作者的声明。应附原始来源，不把作者自述直接写成“本站实测”。
2. **独立推导分析：** 根据公开规格进行的字节计算、通信预算、设计取舍比较和示例程序。尽可能列出公式、输入和假设，让其他工程师能复算。理论吞吐不等于实测吞吐。
3. **实物验证结果：** 真实硬件测试。需要提供设备型号、固件版本、测试方法、环境条件和可核对的数据。没有这些信息的内容，不应被读者理解成硬件性能认证报告。

在资料整理、翻译和起草过程中，我们可能使用 AI 辅助工具，但生成内容不是一手资料，更不能替代仪器测量或真实固件日志。文章的技术价值应来自读者可以核实的资料、明确的计算以及能复用的工程判断，而不是堆积字数和发布频率。
