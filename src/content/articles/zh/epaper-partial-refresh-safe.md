局刷被当作"加速功能"来卖:刷新时间只有一小部分、不闪全屏、更省电。这些都对,但都带条件。在错误的硬件上,或者经过一串错误的更新顺序之后,它会带来对比度偏弱、可见接缝,以及全刷也未必能清掉的残留。

所以问题不是"我的驱动支不支持局刷",而是"这块屏、这个模式、这个温度、这种内容,能不能局刷"。

## 局刷到底跳过了什么

全刷会让每个像素经历多次翻转,不管它原来在哪,最后都停在一个确定状态。局刷把大部分工作跳过了:只寻址一块区域,施加一个翻转更少的短波形,其余像素不动。

这就是它快、不闪的原因,也是它"结果取决于像素原本状态"的原因——这一点在[残影那篇](/zh/articles/epaper-ghosting-causes-and-fixes/)里展开。这里的问题更窄:既然有这个依赖,哪些更新适合走局刷?

## 门槛一:面板和波形支持

这不是软件开关。面板出厂要么带局刷波形,要么不带;控制器还要暴露区域寻址模式。有些模组在数据手册里直接写明只支持全刷,大尺寸面板尤其如此。

写代码之前确认三件事:

1. 商品页或数据手册提到局刷,并给出温度范围。
2. 控制器手册里有局刷/区域更新命令,并说明它对 LUT 的影响。
3. 厂家示例里有**这个面板版本**能跑的局刷例程,而不是同尺寸兄弟型号的。

三条缺一条,就按"不支持"处理。把局刷命令发给没有对应波形的面板,通常不会报错——它会给出一个发灰、低对比的画面,看起来像对比度 bug。

## 门槛二:自上次全刷以来模式没变过

局刷波形假设像素还停在上次全刷留下的状态。改动下面任何一项,这个假设就破了:

- 调色板或颜色模式
- 旋转或镜像
- 显示窗口/局刷窗口的几何
- 波形表(比如温度分档切换之后)

出现以上任何一项,先做一次全刷。就这一条策略,能挡掉大部分"局刷模式颜色不对"的反馈。

## 门槛三:温度在局刷允许的范围内

局刷波形的余量比全刷小:翻转次数少、稳定时间短。低温下颜料走得慢,更新"完成"了却没有到达目标状态,屏上就是发白、带残影的画面,看起来和软件 bug 一模一样。

厂商都会给工作温区,有些还会单独给局刷温区。低于它,强制全刷。不要靠"多等一会儿"来补偿——决定像素落点的是波形,不是超时时间。

## 哪些内容适合局刷

| 更新内容 | 能否局刷 | 原因 |
| --- | --- | --- |
| 时钟数字、状态图标 | 可以 | 面积小、对比变化小、频率高 |
| 一段文字重排 | 可以,但要计预算 | 文字边缘靠边缘保护,而不是抖动 |
| 一张照片 | 不行 | 大面积色调变化,残留最明显 |
| 整屏反色(深色模式切换) | 不行 | 每个像素都变,必须全刷 |
| 大面积色块变色 | 不行 | 短波形最吃力的场景 |
| 上电第一帧 | 不行 | 此时没有任何已定义状态 |

规律很清楚:局刷适合**小面积、增量、低对比**的更新;任何重绘大面积或整屏反色的操作都不适合。

## 接缝与亮度不均

区域局刷有时会在"更新矩形"和"未更新区域"之间留下可见边界。两个原因:

- **历史不同。** 更新过的区域走的是短波形,周围没有。
- **温度不同。** 这块区域刷新时的温度,和其余区域上次全刷时的温度不一样。

如果在正常观看距离就能看到接缝,说明局刷预算已经用完。全刷能清掉;不理它就会累积。

## 能保证安全的策略

每次更新前评估三道门:

```
if (!panel_supports_partial)          -> 全刷
if (mode_changed_since_last_full)     -> 全刷
if (temperature < partial_min)        -> 全刷
if (partial_count >= PARTIAL_BUDGET)  -> 全刷
else                                  -> 局刷,partial_count++
```

预算值是产品决策,不是数据手册上的数字。从 10–20 次开始,用自己的内容验证:每分钟只改几个字符的状态屏,能承受的预算远大于经常换照片的屏。

如果控制器支持指定局刷窗口,再加一道**面积门**:变化区域超过屏幕一半左右,直接全刷。反正波形成本已经付了,而且残留风险更高。

## 在自己面板上怎么验证

别信厂家示例。用自己的内容跑这个序列:

1. 全刷刷一帧"大黑块 + 小字"的画面,拍照。
2. 连续做十次只改小区域的局刷,每次拍照。
3. 在固定光源和曝光下,比较十帧里"未改动区域"。
4. 做一次全刷,再拍照,和第 1 步比。

未改动区域稳定、全刷后能回到第 1 步的画面,说明这个预算在你的面板上安全。区域在漂移,就降低预算。如果全刷都回不到第 1 步,你已经在用最贵的方式找到这块屏的极限了——降低预算,并停止对这类内容用局刷。

## 我们不知道的部分

我们没有针对具体型号做过局刷寿命测试,这个数字也很少有厂商公开。上面三道门是结构性的:它们来自波形的工作方式,不来自某次测量。真正的预算由你的数据手册、温区和内容决定。
