## 一、收集哪些信息

**服务器与安全日志。** 托管与 CDN 服务商 Cloudflare 会处理完成一次请求所必需的技术数据：IP 地址、浏览器与设备类型、请求的 URL、来源页面、时间以及安全事件。任何网站服务器都需要这些数据才能运行和抵御滥用。

**聚合流量统计（无 Cookie）。** 每个页面都会加载 Cloudflare Web Analytics。它以聚合方式统计页面浏览量和来源，不使用 Cookie，也不会跨站构建你的画像。无论你是否同意可分析，它都会运行——因为它不在你的设备上存储任何东西。

**可分析工具——仅在你点击「同意」后加载。** 按「同意分析」后才会加载两个工具：

- **Microsoft Clarity**：交互分析，记录点击、滚动、页面布局与渲染数据，可拼合为一次会话回放。
- **PostHog**：事件分析。此处配置为关闭自动捕获、关闭页面浏览记录、关闭会话录制，且不写入持久标识（仅存于内存，不在你的设备上留存）。

两者在当前浏览会话内保持加载。若你拒绝，则两者都不会被请求：没有脚本、没有请求、没有 Cookie。

**邮件表单。** 规格书与笔记的表单会收集你的工作邮箱、可选的公司名，以及你关注的尺寸。提交内容通过 **Resend**（我们的邮件发送服务商）投递到我们的邮箱，并保存在我们的 Cloudflare 账户中，用于给你发送资料与笔记。我们只用这个地址发送你索取的内容和回复咨询，不做其他用途。每封笔记都附带退订方式，直接回复「stop」同样有效。

**「商务合作」页的询盘表单不会上传任何内容。** 它在你的浏览器里拼好一封邮件，交给你自己的邮件客户端。除非你按下发送，否则不会有任何数据到达我们的服务器。

**站内搜索。** 搜索由 Pagefind 完成：索引下载到本地，查询在你的浏览器内匹配。搜索词不会发送给我们。

**评论。** 文章页可通过 **Giscus** 展示评论，讨论内容存放在 GitHub Discussions。打开或使用评论会涉及 GitHub：如果你登录发言，则涉及你的 GitHub 账号与 GitHub 的 Cookie。阅读文章无需任何账号。

**你主动发来的邮件。** 我们会收到你的地址和邮件内容，并在答复问题、保留勘误记录所需的期间内保存。

## 二、Cookie 与本地存储

| 项目 | 设置方 | 用途 | 期限 |
|---|---|---|---|
| `embeddednote_analytics_choice_v1` | 本站（localStorage） | 记住你选择同意还是拒绝分析 | 直到你清除站点数据 |
| 安全与路由 Cookie | Cloudflare | 机器人防护与请求路由 | 会话期至数日，以 Cloudflare 为准 |
| `_clck`、`_clsk` | Microsoft Clarity | 区分访问以做交互分析 | 最长 1 年 |
| 无持久存储 | PostHog | 本站配置为仅存于内存 | — |
| GitHub Cookie | GitHub / Giscus | 仅在你使用评论时 | 以 GitHub 为准 |

本站没有任何广告 Cookie。

## 三、广告

**本站不投放广告。** 原先引入的广告加载脚本已于 2026 年 11 月移除——它既没有展示出任何广告，又会在访客做出选择之前就向 Google 发起请求。

如果将来引入广告，本页与同意横幅会先作出说明，且在你被询问之前不会加载任何非必要内容。

## 四、处理目的与合法性基础

- **提供网站并保障安全**：运营网站、抵御滥用的正当利益。
- **无 Cookie 的聚合流量统计**：了解哪些文章被阅读的正当利益；不写设备存储，不做跨站画像。
- **Clarity 与 PostHog**：基于你的同意；你可以随时清除站点存储，或在下次访问时选择拒绝。
- **发送你索取的资料与笔记**：应你的请求所采取的措施。
- **回复咨询、保留编辑记录**：正当利益，以及在适用情况下的法律义务。

## 六、保存期限

咨询与订阅记录在商业或编辑关系存续期间保存，之后按法律、税务或争议处理所需的期限保存。服务器日志遵循 Cloudflare 的保留策略，分析数据遵循服务商的保留设置。你可以随时要求删除你的咨询记录，除法律要求必须保留的情形外，我们会执行。

依据你所在地的法律，你可能有权访问、更正、删除或获取个人数据的副本，有权反对或限制处理，并有权撤回同意。请写信至 **[xudeng@datadelta.cn](mailto:xudeng@datadelta.cn)**，我们会在适用法律规定的期限内答复。为确认请求确实来自你本人，我们可能会先问一两个问题核实。

你也可以不联系我们而直接拒绝可分析：在横幅上选择拒绝，或清除本站存储后重新选择。
