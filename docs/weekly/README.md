## 写这一份的规则

1. **每条都要有"发现 → 问题 → 改动 → 线上链接 → 验证"**,缺一环就不写进来。
2. **只写能验证的**。没有链接、没有检查结果的改动,不算完成。
3. **未处理的单独列**,写清为什么没做、卡在哪、归谁。
