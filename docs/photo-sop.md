# 电子纸产品实拍 SOP

适用于:E6 尺寸页头图、画框方案书、选型页、数据集镜像的实拍证据。

**目标**:同一套照片放在同一组页面上,读者一眼能看出“这是同一个人的工作台,不是素材拼凑”。买家判断供应商是否真实,靠的就是这种一致性。

---

## 0. 每块屏拍四张

| 编号 | 名称 | 拍什么 | 用途 |
|---|---|---|---|
| **A** | 关机 | 面板正面,全白/空白,含边框与外形 | 尺寸、外形、边框宽度的第一印象 |
| **B** | 规格卡 | 面板上显示 1:1 规格卡 | **证明这块屏真的点亮了**,且参数可核对 |
| **C** | 内容图 | 面板上显示一张真实内容(照片/海报/图表) | 颜色还原、对比度、可视角度 |
| **D** | 接口 | 背面的 FPC、驱动板、丝印与标签 | 买家判断能不能接、是什么版本 |

可选的第五张:**E 参照物**——手、尺子或 A4 纸同框,给出比例感。这一张最容易被转贴。

---

## 1. 器材

### A 档:只用手机(最低可行)

- 手机主摄(不要用 0.5x 超广角,**会变形**)
- 三脚架或手机夹 + 一本书垫平
- 一张哑光白纸或灰卡(当背景,别用带 logo 的垫子)
- 台灯两盏 + 白纸当柔光罩

### B 档:能出专业图

- 无反/单反 + 50mm 左右定焦(减少畸变)
- 两盏柔光灯(45° 双侧),或一扇朝北的窗
- 偏振镜(CPL)——**消玻璃反光的关键**
- 灰卡(自定义白平衡)
- 快门线或 2 秒延时

---

## 2. 拍摄环境

**背景**
```
✓ 哑光白/浅灰纸,或纯色墙
✗ 带 logo 的皮垫、木纹桌面、杂乱的线材
```
之前踩过:那块皮革垫上有学院标志,**不能出现在公开照片里**。

**光线**
```
✓ 两侧 45° 柔光,或阴天窗光
✓ 关掉顶灯(会在玻璃上留一块亮斑)
✗ 直闪、单侧硬光
✗ 混合色温(暖灯 + 窗光)
```

**相机位置**
```
✓ 镜头正对面板中心,光轴垂直于屏面
✓ 屏面占画面 80% 以上
✗ 斜着拍(后期透视校正会丢边缘像素)
✗ 俯拍(会有反光和梯形)
```

**一致性**:用胶带在地面标出三脚架三个脚的位置,整批都放同一处。这是“看起来像一套”的唯一秘诀。

## 3. 四张的具体拍法

### A 关机

```
状态    断电,屏面停在最后一次全刷后的白底(不要留图案)
构图    面板居中,四周留 8–10% 边距,能看见完整边框
对焦    对在面板边缘或边框上(不要对白屏,会跑焦)
```

### B 规格卡

这一张最有价值,也最容易做砸。

```
内容    型号 · 尺寸 · 分辨率 · 有效区 · 每帧字节 · 拍摄日期
版式    1:1,严格按面板原生分辨率生成,不要缩放显示
配色    只用面板自己的颜料,不加渐变、不加阴影
字号    正文最小 24 px(按原生分辨率算),否则拍出来糊
导出    PNG,无压缩伪影
```

**显示方式**:用面板自己的驱动和固件推图,让 1 个像素对应 1 个物理像素。**不要用图片查看器缩放**——缩放会插值,规格卡上的字就废了。

### C 内容图

```
选图    自己拍的或 CC0,不要用带第三方版权/logo 的图
内容    一张有渐变、有文字、有肤色的图最能体现颜色能力
亮度    选中间调,避免大面积纯白(会过曝)和纯黑(看不出层次)
```

### D 接口

```
角度    背面 45°,能同时看到 FPC 走向和丝印
光线    侧面打光,让丝印有轻微阴影(否则拍平了看不清)
对焦    对在连接器上
注意    遮住客户名、订单号等敏感丝印
```

## 4. 相机设置

**手机**
```
镜头      主摄(1x)
对焦      长按锁定到面板边缘
曝光      锁定后手动减 0.3–0.7 EV(白屏容易过曝)
HDR       关闭(会破坏颜色一致性)
格式      最高质量 JPEG 或 RAW(有的话)
防抖      用 2 秒延时,别用手按
```

**单反/无反**
```
光圈      f/8 左右(景深够,避免边缘发虚)
ISO       100–200
快门      1/60 以上,配合三脚架
白平衡    用灰卡自定义,整批不换
格式      RAW
```

---

## 5. 后期处理(顺序不能乱)

```
① 透视校正    按面板上边缘拟合直线,校到水平
② 裁切        裁到有效显示区,核对长宽比(如 0.7495 对 0.75)
③ 白平衡      白纸/灰卡取样,整批同一组数值
④ 曝光        提到白底接近 250,但不要过曝
⑤ 去除灰尘    用修复画笔,不要用模糊
⑥ 导出        长边 1600 px,WebP q80,同时出 640 px 版本
```

**不要做**:滤镜、HDR、锐化过度、把屏面裁成非真实比例。

## 6. 命名与元数据

```
文件名    e6-13-3-a-off.webp
          e6-13-3-b-spec.webp
          e6-13-3-c-content.webp
          e6-13-3-d-interface.webp
```

- 去掉 EXIF 里的 GPS
- 转换 sRGB
- 单张 WebP ≤ 250 KB
- **说明文字写在 HTML 里,不要烤进图**(否则没法翻译、没法被搜索引擎读)

**alt 示例**
```
E6 13.3 寸六色电子纸面板的规格卡,显示 1200 × 1600 分辨率和每帧 960,000 字节
```

## 7. 验收清单

拍完逐条打勾:

```
[ ] 四张齐全,文件名规范
[ ] 背景干净,没有第三方 logo
[ ] 没有反光斑块
[ ] 规格卡上的字清楚可读
[ ] 面板边缘完整,没有裁掉
[ ] 长宽比与真实面板一致
[ ] 白平衡一致(并排看四张像同一天拍的)
[ ] 单张 ≤ 250 KB,都有 640 px 版本
[ ] alt 文字已写
[ ] EXIF 已清理
```

## 8. 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用超广角拍 | 边框变形,像假图 | 主摄或 50mm |
| 顶灯直射 | 玻璃上一块白斑 | 关顶灯,双侧柔光 |
| 用查看器显示规格卡 | 字被插值糊掉 | 用面板固件 1:1 推图 |
| 白屏过曝 | 看不出边框和工艺 | 减 EV |
| 每张重新对白平衡 | 一套图颜色不一 | 固定一组数值 |
| 把说明写进图里 | 无法翻译、无法索引 | 写在 HTML |

## 9. 时间与批次

```
单块屏        4 张 × 3 分钟 ≈ 15 分钟
布景一次      30 分钟(含对光、标三脚架位置)
后期          每块 10–15 分钟
```

**建议批次**:一次布景拍完一个尺寸段的全部面板(如 1.18 / 1.54 / 2.61 / 2.9),不要一天换三个背景。先拍 **13.3 寸**——它是画框主力,也是最能验证版式的一块。
